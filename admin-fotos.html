📸 Administrar Fotos

¡Súper fácil! En 2 pasos tendrás tus fotos en la web

1

🍞 Pon tus fotos en la carpeta correcta

Arrastra las fotos a la carpeta que corresponda. ¡Así de simple!

🍞 Pan (Bread) 🍽️ Comida (Food) ☕ Bebidas (Drinks) 🍰 Dulces (Sweet)
💡 Tip: Si la carpeta "photos" no existe, créala. Puedes tener "photos" o "PHOTOS" (mayúsculas).
2

🔄 Actualizar la página

Después de añadir tus fotos, ejecuta el actualizador para que aparezcan en la web.

Opción A - Más fácil (Windows):

El archivo está en la carpeta del proyecto. ¡Busca "Actualizar Fotos.bat" y dale doble clic!

Opción B - Desde la consola:

npm run actualizar-fotos

📂 Estructura de carpetas

├── photos/          (o PHOTOS/)
│   ├── Bread/       🍞 Panes
│   ├── Food/        🍽️ Comida salada
│   ├── Drinks/      ☕ Bebidas
│   └── Sweet/       🍰 Dulces y pasteles
├── Actualizar Fotos.bat   ← Doble clic aquí
└── admin-fotos.html      ← Estás aquí
